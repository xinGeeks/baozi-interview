# Alpha 计划

> 目标:把 v0.3 MVP 开放给真实用户,验证产品力 + 收集反馈

## 时间窗

- **起**:2026-07-29
- **止**:2026-08-25(4 周)
- **每周同步**:周日晚汇总当周数据,周一会发出下周调整

## 目标用户(10-30 人)

### Tier 1(优先,10-15 人)

- **产品/工程朋友**:能容忍 BUG,反馈详细,愿意义务帮测
- **目标人群**:3-8 年经验的技术求职者(社招中级/高级)

### Tier 2(补足,5-10 人)

- **陌生求职者**:通过产品社区/即刻/V2EX 招募
- **筛选标准**:近 3 个月在找工作的(避免"产品自用党"无真实场景)

### Tier 3(扩展,5-10 人)

- **学生/转行人群**:校招 / 实习档用户
- **价值**:验证 6 档分级在低经验档的可用性

## Success Criteria(4 周结束时)

### 硬指标(必须达标)

| 指标 | 目标 | 说明 |
|---|---|---|
| **完成面试数** | ≥ 30 场 | 用户真正完成 5 轮问答并出报告的场次 |
| **独立用户数** | ≥ 10 人 | 至少 10 位不同 candidate_id |
| **崩溃率** | < 1% | streamlit 整页挂掉 / 未捕获异常次数 ÷ 总调用 |
| **报告生成成功率** | > 95% | 排除 LLM 平台问题后 |

### 软指标(尽量达标)

| 指标 | 目标 | 说明 |
|---|---|---|
| **每场平均轮数** | ≥ 3 轮 | 用户愿意聊下去 |
| **历史区使用率** | ≥ 30% | 至少 30% 的用户会回看历史 |
| **建议反馈数** | ≥ 20 条 | 来自真实用户的可执行建议 |
| **NPS(简易)** | ≥ 30 | "是否愿意推荐给朋友"10 分制,≥ 7 分比例 |
| **次日留存** | ≥ 20% | 至少 20% 的用户隔天会再来 |

## 数据收集方式(alpha 阶段)

- **匿名 usage**:每位用户的场数 / 轮数 / 留存(已存 SQLite)
- **可选项**:NPS 通过 `docs/nps-survey.md` 链接(自愿填,不强制)
- **不收集**:对话内容、简历内容、个人身份信息

## 风险与回滚

| 风险 | 触发条件 | 应对 |
|---|---|---|
| **成本超支** | 某用户单日 token 飙到 cap 5 倍 | 调高 `LLM_DAILY_TOKEN_CAP` 全局,或限速 |
| **大面积崩溃** | crash 率 > 5% | 暂停邀请新用户,优先修 BUG |
| **PII 泄漏** | data/interviews.db 被公开上传 | 推送删除指引(已在 docs/privacy.md) |
| **平台限流** | 平台 rate limit 持续触发 | 暂停 24h,联系平台方 |

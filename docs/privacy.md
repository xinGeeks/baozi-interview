# 隐私政策与 ToS

> 版本 v1 · 生效日期 2026-07-22 · 适用 BaoZi-Interview Streamlit MVP

---

## 1. 我们收集什么

| 数据类型 | 收集时机 | 存储位置 | 存储期限 |
|---|---|---|---|
| **简历原文** | 你点"上传简历 (PDF)"时解析 | **不持久化**,仅在内存中用于本场面试 | 面试结束 / 关闭页签后清空 |
| **JD 文本** | 你粘贴到主区文本框 | 仅前 200 字摘要 + MD5,存 SQLite | 默认 30 天(可配 `STORAGE_RETENTION_DAYS`) |
| **面试对话** | 你与 AI 面试官的问答 | SQLite `interview_turns` 表 | 默认 30 天 |
| **每轮反馈** | AI 评分与建议 | SQLite `turn_feedback` 表 | 默认 30 天 |
| **报告文本** | "生成报告"时 | SQLite `interview_sessions.report_text` | 默认 30 天 |
| **ToS 接受记录** | 你点击"确认接受"时 | SQLite `consent_log` 表 | 永久(仅 candidate_id + 版本号 + 时间戳) |
| **错误日志** | 异常兜底写入 | `data/error.log`(本地) | 永久(只记异常类型 + 截断 200 字) |

## 2. 我们不做什么

- ❌ 不把简历原文、对话、报告上传到任何第三方服务
- ❌ 不存你的姓名、邮箱、电话(简历解析时不主动抽取)
- ❌ 不做跨设备同步 / 不做账号体系(alpha 阶段本地单用户)
- ❌ 不向 MiniMax 平台发送除 prompt 之外的任何字段
- ❌ 不写 cookie / 不做行为分析(无 Google Analytics / 无埋点 SDK)

## 3. 你的权利

| 权利 | 如何行使 |
|---|---|
| **删除某场面试** | sidebar 历史区 → 点 🗑️ → 二次确认 |
| **清空全部历史** | sidebar 底部 → 输入"确认删除" → 一键清空 |
| **查看本地数据** | `data/interviews.db`(SQLite 文件,可用任意 SQLite 工具查看) |
| **拒绝上传简历** | 不点 file_uploader;只粘贴 JD 也能跑(启发式部分会弱化) |
| **拒绝 ToS** | 直接关闭页签;无任何数据被持久化(consent_log 无记录) |

## 4. 数据安全

- **本地优先**:所有数据存你本机的 `data/interviews.db`,不进任何云
- **PII 最小化**:candidate_id 用 MD5(简历原文)派生,不可逆;不可由 ID 反推简历
- **保留期可控**:`.env` 中 `STORAGE_RETENTION_DAYS=0` 可禁用自动清理
- **错误日志脱敏**:`data/error.log` 只记 `type(e).__name__ + str(e)[:200]`,不记 resume 字段

## 5. 风险与限制

- **本地数据库 = 你机器的安全等级**:`data/interviews.db` 文件若泄露,他人可读取对话内容。**请勿在公共电脑使用本工具**。
- **alpha 阶段不承诺 SLA**:无 99.9% 可用性,服务可能随时改动 / 弃用
- **错误日志可能含 prompt 摘要**:若 LLM 返回超长内容被截断入日志,可能间接暴露 JD 片段

## 6. ToS 全文(法律条款)

### 6.1 你承诺

- 简历与 JD 内容真实,无虚假信息
- 不上传他人简历、机密信息、违法内容
- 不用本工具做商业转售 / 二次分发

### 6.2 我们承诺

- 不存简历原文(详见第 1 节)
- 不向第三方分享数据
- 30 天后自动清理历史(可关)
- 错误日志脱敏,不含 PII 字段

### 6.3 免责

- 本工具**不构成录用判断**,报告仅作求职者自查参考
- LLM 输出可能含偏见、错误,使用方应自行判断
- 因网络、平台故障导致的数据丢失,我们不承担责任
- alpha 阶段功能可能变更,文档与代码可能不一致,以 `openspec/specs/` 为准

### 6.4 变更通知

- 重大变更将 bump `TOS_VERSION` 并触发 ToS 重新接受
- 版本号格式:`YYYY-MM-DD-vN`(日期 + 顺序号)
- 当前版本:`2026-07-22-v1`
